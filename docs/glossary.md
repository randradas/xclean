# Glossary

Project words only. One or two lines each. Use these words in code, specs, and talk.
Format: **Term**: what it is. `_Avoid_:` words that mean the same thing but should not be used.

**Spec**:
What a feature must do and why. No how.
_Avoid_: PRD, story, ticket

**Plan**:
How a spec will be built.
_Avoid_: design doc, RFC

**Task**:
A small, testable step of a plan.
_Avoid_: step, todo

**Post**:
Content a user published on X: an original post, a reply, or a quote post.
_Avoid_: tweet, status

**Repost**:
A user sharing someone else's post as is, without adding text. Removing one means undoing it.
_Avoid_: retweet, RT

**Content type**:
A kind of user content or activity xclean can remove, such as posts, reposts, or likes.
_Avoid_: kind, category

**Rule**:
A condition that selects which items to remove, such as a date range or a content type.
_Avoid_: filter, criteria

**Keep list**:
Items the user marks as never to be removed, whatever the rules say.
_Avoid_: allowlist, whitelist, exceptions

**Preview**:
What a run would remove, with counts, estimated cost and time, before anything is removed.
_Avoid_: dry run, simulation
